# TAOAM Book Companion

An educational companion to The Atlas of Advanced Mathematics, published by Ouviaj LLC. Ask about mathematical terms, concepts, theorems, methods, and symbols. The companion presents explanations through What It Is, How It Is Used, A Closer Look, and Further Reading.

## Add to Claude

This plugin is a local release candidate and has not yet been listed in Anthropic's directory. Once the listing is approved and published, open its directory page in Claude and choose Add. After adding it, use the + menu or type / to select its skill and ask your question. A directory installation does not require manually downloading and uploading the archive.

For a local installation check before publication, open Claude's Plugins page, choose Add, then Upload plugin, and select the release ZIP. Older interfaces place this under Customize > Plugins. Verify the skill appears and test it in a reader conversation. If you already have the standalone Companion Skill, disable that copy when testing the plugin to avoid duplicate entries.

## What is included

The existing Claude Skill is preserved byte for byte. The package contains the Skill, a Claude plugin manifest, the existing Ouviaj logo, and the existing published Companion terms. It declares no MCP connector, local server, executable, hook, or external account configuration. Host-platform capabilities and account rules still apply. Adding the plugin does not purchase the Atlas or unlock protected Topic Guides.
